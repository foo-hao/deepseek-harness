# Agent Note: 可配置的空闲 Enter 行为

Status: implemented

[English](2026-09-08-composer-idle-enter-mode.md) | 中文

## Problem

编写多行指令的用户需要明确选择普通 Enter 是发送消息还是插入换行。智能体运行中的排队与插话偏好控制的是另一项交互。

## Decision

会话设置拥有空闲 Enter 模式，默认发送，也可选择换行。Host 设置服务持久化该选择。设置行与常驻输入框订阅同一偏好来源。

Lexical 命令处理器先处理 Shift+Enter、输入法组合与菜单仲裁。在可编辑的空闲换行模式下，普通 Enter 交给编辑器的换行处理器。空闲时 Cmd/Ctrl+Enter 提交。繁忙输入继续通过提交策略解析排队或插话；锁定和裁决中的输入保留现有保护。换行模式占位提示保留当前操作说明并追加快捷键解释。

## Alternatives considered

默认换行会改变现有用户的普通发送手势。共用一项空闲与繁忙偏好会把多行编辑和运行中的消息投递耦合起来。分别设置可保留两种工作方式。设置由已有编辑器键盘映射和繁忙偏好的会话领域实现；生态实现依赖双方认可的客户端扩展约定。

## Consequences

多行编写者可选择原生换行，同时保留明确的加速发送手势。维护验证涵盖设置持久化、偏好即时更新、编辑器草稿同步、输入法与菜单优先级、锁定输入及空闲与繁忙的快捷键组合。
