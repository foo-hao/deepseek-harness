# Agent Note: 许可证查找跳过不完整的虚拟存储条目

Status: implemented

[English](2026-09-12-notices-incomplete-virtual-store.md) | 中文

## Problem

可选依赖安装中断可能留下仅含空 node_modules 目录的版本条目。许可证生成器的前缀查找在核对请求版本前读取清单，因此较早的不完整条目会终止生成，即使所需版本已完整安装在存储中的其他位置。

## Decision

前缀查找在读取前检查候选清单是否存在，与现有的全存储回退查找保持一致。缺失候选允许继续查找完整的前缀条目或名称截断条目。遍历结束返回 undefined，由调用者负责必需包的诊断。存在的清单正常解析，保留对损坏内容的错误报告。

## Alternatives considered

手工清理残留目录可修复单次安装，但要求贡献者自行管理包管理器残留。捕获所有读取或解析错误会掩盖损坏的元数据。检查候选是否存在可以处理不完整条目，同时保留现有内容校验。

## Consequences

生成许可证说明时，可选安装残留可以与完整包版本共存。回归夹具覆盖较早不完整条目之后的常规及截断名称完整条目、完全缺失的请求安装，以及存在但损坏的清单。每个夹具独立创建并清理临时存储。
